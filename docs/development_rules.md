# Règles de développement

## Python
- utiliser Python 3.11+
- garder le code lisible et simple
- écrire des fonctions courtes
- utiliser des types explicites

## Pydantic
- utiliser des modèles pour les entrées et sorties
- ne pas manipuler de dictionnaires partout
- valider les données structurées

## Tests
- écrire des tests unitaires dès qu'une fonctionnalité est ajoutée
- tester le comportement réel
- éviter les mocks inutiles

## Git et GitHub
- travailler sur des branches par sujet
- faire des commits clairs
- utiliser des Pull Requests pour comparer les changements
